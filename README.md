🌱 Jathr | جذر

Jathr is a digital nutrition consultation platform designed to organize and simplify communication between clients and nutrition specialists.

✨ Features

* Appointment booking
* Dietary plans
* Laboratory result uploads
* Health progress tracking
* Weekly follow-ups
* Online payments
* Client & specialist dashboards
* Zoom session access
* File management

🎯 Goal

To provide a centralized, secure, and organized platform for managing nutrition consultations and client progress.
